Activities are designed to provide enough guidance for beginners while still requiring learners to perform the work themselves.

The complete solution is not provided immediately so that learners have an opportunity to apply the concepts independently.

---

## Assessment Strategy

Assessments use multiple methods to measure different levels of understanding.

### Knowledge Checks

Multiple-choice questions measure foundational conceptual understanding.

Examples include:

- Identifying a class.
- Identifying an object.
- Recognizing fields and methods.
- Understanding object creation.

### Short-Answer Questions

Short-answer questions measure whether learners can explain concepts in their own words.

### Application Tasks

Programming tasks measure whether learners can apply concepts independently.

### Reflection

Reflection questions encourage learners to identify strengths and areas that require additional practice.

---

## Assessment Alignment

Assessment tasks are directly aligned with the learning objectives.

| Learning Objective | Assessment Method |
|---|---|
| Explain the difference between a class and an object | Multiple-choice + short answer |
| Identify fields and methods | Multiple-choice |
| Explain object creation | Multiple-choice + short answer |
| Create objects from a class | Programming task |
| Apply class and object concepts | Programming task |

This alignment ensures that learners are assessed on the skills and knowledge they were expected to develop.

---

## Rubric Design

Practical programming tasks are evaluated using a rubric.

The rubric separates performance into individual criteria rather than relying only on whether the final program works.

Example criteria include:

- Correct class definition
- Correct fields
- Correct methods
- Object creation
- Object state
- Program execution

This makes evaluation more transparent and provides more useful feedback to learners.

---

## Feedback Strategy

Feedback is designed to be:

- Clear
- Specific
- Actionable
- Encouraging
- Connected to the learner's performance

Feedback should help the learner understand:

1. What they did correctly.
2. What needs improvement.
3. What they should review or practice next.

Performance-based feedback levels are used to guide learners toward the appropriate next step.

---

## Progression Model

Learners should demonstrate sufficient understanding before progressing to more advanced concepts.

The general progression is:

```text
Understand
   ↓
Practice
   ↓
Apply
   ↓
Assess
   ↓
Review if needed
   ↓
Progress
```

A learner who does not meet the required assessment threshold should review the relevant material and repeat the activity before progressing.

## Learner-Centric Design Principles

The program follows several learner-centric principles.

### Clear Language

Technical concepts are explained using simple and accessible language.

### Progressive Complexity

Concepts are introduced from simple to more complex.

### Practical Application

Learners apply concepts through realistic programming scenarios.

### Immediate Practice

Activities follow learning content so learners can immediately apply newly introduced concepts.

### Multiple Ways to Demonstrate Understanding

Learners demonstrate understanding through:

Questions
Explanations
Programming
Reflection
### Self-Assessment

Checklists and reflection questions allow learners to monitor their own progress.

### Remote Learning Considerations

The learning materials are designed for independent and remote learning.

### The content therefore:

Provides clear written instructions.
Defines expected outcomes.
Uses self-contained activities.
Includes success criteria.
Includes assessment guidance.
Minimizes dependence on live instruction.
Allows learners to review concepts independently.
### Quality Assurance

Learning materials should be reviewed for:

### Content Accuracy

Technical concepts and programming examples should be accurate.

### Instructional Alignment

Activities and assessments should measure the stated learning objectives.

### Clarity

Instructions should be understandable to the intended audience.

### Consistency

Terminology, formatting, difficulty, and structure should remain consistent across modules.

### Accessibility

Content should use clear headings, readable formatting, descriptive instructions, and manageable learning sections.
