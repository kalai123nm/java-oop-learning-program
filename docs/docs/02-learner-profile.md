# Learner Profile

## Primary Audience

Beginner programmers who have learned basic Java syntax but have
limited practical experience with object-oriented programming.

## Learner Characteristics

- Familiar with basic Java syntax
- Can write simple programs using variables, conditions, loops, and methods
- Has limited experience designing classes
- May understand OOP terminology but struggle to apply it
- Benefits from concrete examples and practical exercises
- Requires gradual progression from simple concepts to integrated problems

## Common Learning Challenges

1. Confusing classes and objects
2. Understanding when and why encapsulation is useful
3. Treating inheritance as simply code reuse
4. Confusing inheritance with polymorphism
5. Memorizing OOP definitions without knowing when to apply them
6. Struggling to combine multiple OOP concepts in one program

## Learning Needs

Learners need:

- Simple explanations
- Visual or conceptual analogies
- Short code examples
- Guided practice
- Immediate knowledge checks
- Scenario-based questions
- Practical coding exercises
- Clear assessment criteria

## Desired Outcome

Learners should move from:

"I know the definitions of OOP concepts"

to:

"I can identify, explain, and apply the appropriate OOP concept when
designing a Java program."
