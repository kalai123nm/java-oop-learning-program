# Learning Objectives

| ID | Learning Objective | Measurement |
|---|---|---|
| LO1 | Identify and distinguish classes and objects and create basic Java classes and objects. | Knowledge check + coding activity |
| LO2 | Explain and implement encapsulation using access modifiers, constructors, getters, and setters. | Scenario question + coding activity |
| LO3 | Explain and implement basic inheritance using parent and child classes. | Knowledge check + coding activity |
| LO4 | Identify and implement method overriding and explain its relationship to polymorphism. | Code analysis + implementation task |
| LO5 | Design and implement a simple Java solution using appropriate OOP concepts. | Final project + rubric |
