Module 1
Classes & Objects

Learner should understand:

What a class is
What an object is
Attributes
Methods
Constructors
Creating objects

Create a Student class.

Assessment:
Knowledge check + coding task.

Module 2
Encapsulation

Learner should understand:

Why data should be protected
Access modifiers
private
Getters/setters
Constructors
Controlled access

Activity:
Build an encapsulated BankAccount.

Assessment:
Scenario questions + coding task.

Module 3
Inheritance

Learner should understand:

Parent class
Child class
extends
Reusing behavior
When inheritance makes sense

Activity:
Create a Vehicle → Car hierarchy.

Assessment:
Conceptual questions + implementation.

Module 4
Polymorphism

Learner should understand:

Method overriding
Runtime behavior
Parent references
Different implementations

Activity:
Create different vehicle implementations.

Assessment:
Code analysis + implementation.

Module 5
Integrated Practice

Learner combines:

Classes + Encapsulation + Inheritance + Polymorphism

into a small application.

Possible project:
Simple Banking System
or
Vehicle Management System
